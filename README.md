## 🐛 Como Reportar um Bug

Se você encontrou um erro, travamento ou comportamento inesperado:

1. Acesse a aba **[Issues](../../issues)** e clique em **New Issue**.
2. Selecione o modelo **Reportar um Bug**.
3. Preencha os campos solicitados: versão do app, versão do Windows, passo do assistente onde ocorreu o erro e o comportamento observado.
4. **Anexo de Diagnóstico Saneado:**
   - No GBX Harness IDE, acesse o menu de **Diagnóstico / Configurações**;
   - Clique no botão **"Exportar diagnóstico"**;
   - O aplicativo gerará um arquivo de diagnóstico higienizado (sem tokens, sem senhas e sem dados sigilosos);
   - Anexe esse arquivo gerado diretamente no corpo da sua issue.
5. Marque a caixa de confirmação atestando que não incluiu dados sigilosos e envie.

## 💡 Como Enviar uma Sugestão

Tem uma ideia para tornar o GBX Harness IDE ainda melhor?

1. Acesse a aba **[Issues](../../issues)** e clique em **New Issue**.
2. Selecione o modelo **Sugestão de Melhoria**.
3. Descreva a área do aplicativo, o caso de uso ou problema enfrentado e a melhoria proposta.
